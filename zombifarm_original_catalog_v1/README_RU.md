# Каталог оригинальной социальной «Зомби Фермы» — v1

Этот пакет собран из исходного `items.json`, оригинального манифеста `assets.csv`, `item_relations.csv` и `locations.csv`. Это данные социальной/VK Flash-игры, а не каталог Castaways.

## Основные цифры

- Записей в исходном items.json: **6264**.
- После удаления только полностью идентичных повторов: **5118** записей с уникальными ID.
- Уникальных типов: **130**.
- Построек: **415**.
- Посевных культур: **55**.
- Рецептов: **64**.
- Обычных локаций: **44**.
- Исследовательских локаций: **37**.

## Файлы

- `items_unique.json` — все записи после удаления только точных дублей; вложенные поля сохранены.
- `items_index.csv` — общий плоский индекс всех записей, сложные поля оставлены JSON-строками.
- `buildings.csv`, `seeds.csv`, `recipes.csv`, `decorations.csv`, `wood_trees.csv`, `fruit_trees.csv`, `stones.csv`, `piers.csv`, `path_parts.csv` — отдельные каталоги.
- `recipes_resolved.csv` — рецепты с попыткой разрешить ID ингредиентов и результата в названия.
- `locations_original.csv`, `exploration_locations.csv`, `locations_manifest_audit.csv` — карты и сведения о локациях.
- `asset_reference_audit.csv` — сверка ссылок на изображения из items.json с оригинальным манифестом.
- `relations_unresolved_grouped.csv` — сгруппированные ссылки из item_relations.csv, которые не разрешились автоматически. Они могут быть динамическими символами/группами, а не повреждёнными записями.
- `key_building_facts.csv` — отдельная подборка ключевых зданий и их механик.
- `type_summary.csv`, `catalog_summary.json` — статистика.

## Про Excel 2019

Все CSV используют разделитель `;` и UTF-8 с BOM, чтобы Excel 2019 открывал кириллицу и столбцы корректно.

## Важные оговорки

`assets.csv` — это манифест оригинального клиента: он сообщает относительный путь, SHA-1 и размер ресурса. Он **не содержит сами байты изображений и SWF**. Поэтому `FOUND` в `asset_reference_audit.csv` означает, что файл указан в оригинальном манифесте, но для извлечения самого изображения нужен соответствующий SWF/ResPack-файл.

Castaways не считается полным источником. Отсутствие объекта или растения в APK Castaways не является доказательством его отсутствия в социальной игре. Все неизвестные объекты следует сохранять со статусом «не знакомо игроку, дата появления неизвестна».
